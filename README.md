# Kofi Website

This folder is ready to publish as a static website.

Files:
- `index.html` is the homepage.
- `cv.pdf` is the CV file linked by the homepage.

To update the website:
1. Edit `index.html`.
2. Replace `cv.pdf` with a newer CV if needed, keeping the same filename.
3. Upload/commit both files to GitHub Pages, Netlify, or another static host.

For a custom .com domain on GitHub Pages:
1. Add the domain in GitHub Pages settings.
2. Add the required DNS records at your domain registrar.
3. Enable HTTPS after DNS verification.
